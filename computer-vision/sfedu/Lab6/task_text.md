В рамках выполнения данной лабораторной работы необходимо выполнить следующие шаги,  

1.    Произвести самостоятельную съемку 3–5 изображений в ряд для последующего построения панорамы  
2.    Загрузить изображения и список с ними отсортировать по номеру кадра в композиции сцены (по порядку съемки)  
3.    Для каждого кадра рассчитать ключевые точки  
4.    Построить матчинг ключевых точек (с фильтрацией стабильных матчей через метод Лоу) между кадрами (i, i+1) и построения матрицы гомографии H(i, i+1) через cv2.findHomography и алгоритмом RANSAC (для матрицы H(i+1, i+2) ну;но учитывать матрицу H(i, i+1))  
5.    Рассчитать размер холста для склейки изображений: взять координаты 4-х точек углов для каждого изображения, применить для них соответствующие матрицы H’, где H’(i+k, i+k+1) = H(0, 1) x H(1, 2) x … x H(i+k-1, i+k) x H(i+k, i+k+1); к советующим 4 точкам применить своё H’ и получить наборы точек по котором рассчитать максимальные и минимальные значения по Ox и Oy координатам, это и будет задавать размер холста  
6.    Отобразить на холст все изображения по их матрицам гомографии  
7.    Обрезать холст для кадрирования без пустых участков
